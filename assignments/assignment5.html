1. What is YAML and why has it become the default configuration format for Kubernetes/Rahti manifests? Compare it briefly to JSON

YAML ("YAML Ain't Markup Language") has become the default configuration format for Kubernetes and Rahti because it is designed to be highly human-readable and relies on clean indentation rather than heavy punctuation. Unlike JSON, which requires numerous curly braces, square brackets, and quotation marks that quickly clutter multi-layered files, YAML allows engineers to clearly structure and read complex deployment specifications, metadata, and container configurations without visual fatigue.

2. List some public APIs and describe a realistic integration you could add to the backend you built in Week 4

A public API is an open web service that allows applications to fetch free data from external sources over the internet, such as Open-Meteo for weather forecasts, CoinGecko for cryptocurrency prices, or Restcountries for geographic data. A realistic integration for this project involves fetching live weather updates from the Open-Meteo API using a lightweight fetch function whenever the user loads the application page, allowing the frontend to dynamically display current environmental conditions directly on the report interface.

3. What is a Web Application Firewall (WAF) and what kinds of attacks does it defend against? Where would you place it in the three-container architecture you built in Week 4 (Route → frontend → backend → db)?

A Web Application Firewall (WAF) is a specialized security layer that inspects actual HTTP web traffic rather than just blocking network ports, protecting web applications from malicious application-layer attacks like SQL injection and Cross-Site Scripting (XSS). In our three-container architecture (Route → frontend → backend → db), a WAF should be placed at the very beginning—right before the OpenShift Route and frontend container—so it can filter and intercept malicious requests before they ever reach the backend API or database.

4. What are open data portals (for example avoindata.fi or the European Data Portal) and why does choosing the right data format matter for reuse?

Open data portals are centralized online repositories where governments, cities, and organizations publish free, publicly accessible datasets (such as public transit timetables, environmental records, or statistical information) for public use. Choosing the correct data format is crucial because structured, machine-readable formats like JSON or CSV allow developers and researchers to easily write automated scripts to parse, filter, and analyze the data, whereas static formats like scanned PDF documents make programmatic reuse difficult.
